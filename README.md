This package contains a historical library of python2 modules that custom TurnKey software
have used.

The modules from this library that are sill in use by TurnKey's current python3 packages have been
moved out into their own individual packages (and updated to python3).

The only TKL software that still depends on code within this library is TKLBAM (as that is still
python2). However, for the v19.x (Trixie based) TurnKey release, the relevant modules from this
repo have been merged directly into the TKLBAM repo - making this repo now completely redundant.
As such it is now archived.
